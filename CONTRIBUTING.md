# Contributing

Thank you for your interest in Probant.

## Report a bug

Open an issue with the **Bug report** form. Give the version of Probant (at the bottom of each page of the tool), the
type of installation, the role of the account, and the steps to reproduce the problem.

Do not include real data: no values, no email addresses, no names of people or of organisations.

## Report a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting, as described in [`SECURITY.md`](SECURITY.md).

## Pull requests

We do not accept pull requests for now. Each version of the tool is published here as one commit, so a pull request
cannot be merged into this history and we close it. Open an issue instead: we read every issue.

## Translations

If a text of the interface is wrong in your language, open an issue with the page, the text, and your suggestion.
